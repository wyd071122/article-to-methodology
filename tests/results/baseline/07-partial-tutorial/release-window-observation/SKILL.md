# 发布窗口观察记录

先阅读 [节选依据与能力边界](references/evidence.md)。本技能只完成第三节已完整定义的人工观察记录，不能从缺失第二节补出发布或回滚制度。

## 输入与校验

取得同一明确时间窗口的起止时间、请求总数 n、失败请求数 f。失败只计入服务端返回 5xx 的请求。保留用户原始数据，逐项核对：

1. 窗口起止明确，n 和 f 对应同一个窗口，失败口径为 5xx。
2. n、f 都是非负整数，且 f ≤ n。
3. 缺少字段、窗口不一致、失败口径不明确或数值不合法时，说明具体缺口或错误，保留可用记录，停止计算确定错误率；只请求修正必要输入。不把缺数当零，不自行取整，不把 4xx 或客户端错误直接归入 f。

窗口表示、错误提示和输出表格属于执行设计；数值和失败定义来自第三节。不要自行补日志、时区、流量或观测结果。

## 计算与记录

- n > 0：错误率 e = f / n；同时输出比例和百分数 (100 × f / n)%。优先保留精确分数，必要时给小数近似并标明舍入，避免把极小非零值误写为零。
- n = 0：合法输入只能为 f = 0。记录“无流量；错误率未定义”，比例与百分数均标为未定义，不输出 0%。
- n = 0 且 f > 0 已违反 f ≤ n，先作为非法输入处理。

输出窗口起止、n（请求数）、f（5xx 请求数）、数据校验结果、错误率比例和百分数或“无流量；未定义”。可明确写明“仅完成观察记录”，不得写“发布成功”或“已回滚”。

## 发布和回滚边界

第四节仅说：连续 K 个窗口的错误率都严格超过 T 才触发回滚，但 T、K 的定义、数值和选取方法来自未提供的第二节。当前技能不据此判断某次是否应自动回滚，不把“超过”改为“大于等于”，不编造默认阈值或连续窗口数，不把“无流量”当作零错误率参与判定。

材料还缺少发布命令、回滚命令和告警接收者。遇到这些任务，指出具体缺口并停止相关执行；可以继续完成已提供窗口的观察记录。仅补 T、K 也不能弥补真实发布、回滚操作和授权等执行依据的缺失。没有执行线上操作时不得声称已经完成。

## 完成标准

完整合法窗口得到可复核的 f/n 和百分数；无流量窗口明确未定义；不合法或缺输入窗口说明原因并停止计算。所有交付均限于本节选明确支持的人工观察记录。
