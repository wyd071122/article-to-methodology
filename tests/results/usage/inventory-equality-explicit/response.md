需求稳定、交货提前期确定且固定，安全库存由计划人员提供，符合本规则的适用前提。输入单位一致，无需换算。

| 输入 | 甲 | 乙 |
|---|---:|---:|
| 平均需求率 d | 10件/天 | 10件/天 |
| 交货提前期 L | 5天 | 5天 |
| 安全库存 S | 0件 | 0件 |
| 现有库存 on_hand | 50件 | 0件 |
| 在途库存 on_order | 0件 | 0件 |
| 已分配库存 allocated | 0件 | 2件 |

两种状态的补货点相同：

**R = d × L + S = 10件/天 × 5天 + 0件 = 50件。**

- **甲：触发补货。**库存头寸 P = 50件 + 0件 − 0件 = 50件。比较：50件 ≤ 50件，等于补货点时也触发。
- **乙：触发补货。**库存头寸 P = 0件 + 0件 − 2件 = −2件。比较：−2件 ≤ 50件。负库存头寸表示短缺。
